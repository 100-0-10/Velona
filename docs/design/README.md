# Velona 기획 자료

현재 저장소 이름은 **Velona**다. `planning/`은 이전 Velora·Wildscape Frontier 가칭으로 정리한 기획 초안이며 기존 파일을 보존했다. 수치·몬스터·제작 데이터는 `data/`에 있고, 실제 초기 구현 범위와 차이는 `../development/`에서 관리한다.

- [전체 기획](planning/00_전체기획.md)
- [지역과 기후](planning/01_지역과기후.md)
- [몬스터와 해체](planning/02_몬스터와해체.md)
- [제작대와 생활](planning/03_제작대와생활레시피.md)
- [장비와 전투](planning/04_장비능력치와전투규칙.md)
- [경제와 운영](planning/05_경제와운영.md)
- [기술 구성](planning/06_기술구성과개발방법.md)
- [데이터 정의](planning/07_데이터정의와연결.md)
- [개발 단계](planning/08_개발단계와완료기준.md)
- [기획 당시 검사](planning/09_검증결과.md)

현재 수정된 데이터의 검사 명령은 저장소 루트의 `node scripts/validate-design.mjs`다. 과거 `validation_report.json`은 기획 당시 결과이며 현재 검사 결과를 대신하지 않는다.

`planning-index-original.md`는 이전 전달 색인을 보존한 자료이며 문서 링크만 현재 폴더에 맞춰 조정했다. 문서의 예전 단계·검사 결과와 현재 구현은 구분한다.
