# 장비 능력치와 전투 규칙

## 기준 수치

플레이어 기본 체력 120, 스태미나 100, 이동속도 4.2m/s를 시험 기준으로 사용한다. 무기의 attack은 기본 공격 1회 기준의 원시 공격력이며 DPS가 아니다. 공격속도는 attack_interval_seconds로 별도 표시한다. 몬스터 attack_raw도 방어 적용 전의 기본 공격 1회 값이다.

물리 피해 = max(1, 공격력 × 기술계수 × 100 / (100 + 대상방어 × (1 - 방어무시율/100))). 기본 공격 기술계수 1. 치명타 확률 5%, 배율 1.5. 최종 피해 단계에서만 반올림한다.

예: 공격력 38의 철창이 방어 18인 대상을 일반 공격하면 약 32 피해다. 1.2초 간격의 이론상 DPS와 실제 회피·추격 시간을 포함한 사냥 시간은 다르다. 목표 사냥 시간은 플레이 검증 후 조정한다.

추가 속성 피해 = 고정 추가값 × (1 - 해당 속성저항/100). 속성저항 상한은 60이다. 물리방어와 중복 적용하지 않으며 추가타·도트는 치명타가 없고 다른 특성을 재귀 발동하지 않는다. 출혈은 물리방어를 다시 적용하지 않는 고정 피해이며, PvP 도입 전 별도 검토한다.

## 장착과 스킬

장착 칸은 무기·보조손·상의·하의·장갑·장화·망토·가방·생활 도구다. 창·활은 양손이므로 방패와 동시 사용하지 못한다. 도검은 한손으로 방패와 조합할 수 있다. 활은 뼈 화살 1개를 발사 시 소비하고 기본 화살 레시피는 제작대에서 제공한다.

창은 2.7m 안팎의 거리와 1.2초 기본 간격, 도검은 1.7m·1.0초, 활은 10m·1.3초를 기준으로 한다. 무기 고유 공통 기술은 창의 긴 찌르기(계수 1.4·스태미나 18·재사용 8초), 도검의 짧은 연계(총계수 1.35·스태미나 16·재사용 8초), 활의 조준 사격(계수 1.5·스태미나 18·재사용 10초)부터 검증한다. 기술 수치도 초안이다.

회피는 스태미나 20, 재사용 1초, 짧은 이동과 0.2초 회피 구간부터 시험한다. 서버가 사용 가능 여부와 판정을 확정한다. 방패의 정면 방어는 물리 피해 45% 감소·기본 스태미나 12 소비를 기준으로 하며 공격 방향·가드 브레이크를 표시한다. 방패의 일반 방어력은 장착 시 합산하고 가드 감소는 방어 행동 중에만 추가 적용한다.

## 품질과 재료

보통·양질·우수 3단계 배율은 공격·방어·최대내구에 각각 1.00·1.05·1.10이다. 환경 저항·효과 발동값·거리·속도·가방 칸 수에는 배율을 적용하지 않는다. 고유 방어력 +2 같은 고정 효과는 품질 배율 적용 후 더한다.

주재료 60%, 보강재 20%, 결합재 20%의 품질 점수 가중합을 사용하며 없는 슬롯의 가중치는 남은 슬롯에 재분배한다. 점수는 보통 0·양질 1·우수 2이며 숙련 보정 최대 0.2, 설비 보정 최대 0.1을 더한다. 1 미만 보통, 1 이상 2 미만 양질, 2 이상 우수다. 원재료의 같은 슬롯 안에 품질을 섞으면 수량 가중평균을 먼저 계산하고 결과 미리보기를 제공한다.

레시피 고정 특성 1개와 명시된 선택 결합재 특성 최대 1개만 사용한다. 같은 효과는 상한과 중복 금지 규칙을 적용한다. 모든 소재가 갖고 있는 속성이 모든 완제품에 무조건 누적되지 않는다. 첫 버전에는 무작위 대성공을 넣지 않는다.

## 특성 상한

공격 스태미나 절감 15%, 가드 소모 절감 20%, 최대내구 보정 30%, 방어무시 15%, 채집시간 절감 15%, 재료 특성의 추가 방어력 합계 10이 상한이다. 같은 장비 안에서는 같은 특성 id를 1회만 적용한다. 서로 다른 장비의 수동 능력치 효과는 합산 후 상한을 적용한다. 적중 발동 효과는 같은 종류 중 가장 높은 하나만 적용하며 여러 부위로 쿨다운을 우회하지 못한다.

출혈·독·냉각·전도 효과는 대상별 적중 수·재발동 대기시간을 사용한다. 같은 종류 도트는 갱신만 하고 무한 중첩되지 않는다. 다른 플레이어의 개인 도트는 소유자를 구분하되 보스에 대한 총 피해 상한은 부하·밸런스 시험에서 검토한다. 장비 교체로 적중 카운터를 보존하지 않는다.

레이드 장비는 동일 단계의 일반 장비보다 반드시 높은 기본 수치를 갖지 않는다. 특성의 성격과 외형으로 보상하며 핵심 성능·환경 장비를 레이드 전용 희귀 추첨으로 막지 않는다.

## 내구도와 수리

무기 유효타 0.04, 도구 채집 행동 0.15, 방어구 유효 피격 0.08 내구도 소모부터 시험한다. 이동·대기·미접속에는 소모하지 않는다. 여러 타격 기술은 기술별 총 마모를 정하고 패킷·판정 횟수로 중복 마모시키지 않는다.

기초 장비는 수리 3회, 중상위는 5회다. 수리할 때 원래 최대내구의 5%씩 최대내구가 감소하며, 남은 내구 비율과 수리 횟수는 개조·염색·거래에도 보존한다. 수명 0이면 사용 불가 파손품으로 남는다. 해체는 일부 기본 재료만 회수하며 고유 부위·기관·결정을 되돌려 무한 제작하지 못한다.

권장 측정: 초급 도구의 첫 수리까지 실제 작업 1~2시간, 중급 장비는 여러 번 원정. 현재 마모 초안이 이 목표와 맞는지는 실제 작업 속도로 검증해야 한다.

## 몬스터 보상과 해체

유효 참여자마다 기본 재료를 받고 집중 부위 1개를 고른다. 식량·일반 외피/골격·고유 부위 중 선택한다. 고유 부위는 일반 생물 1개, 정예·레이드 2개 확정이다. 표의 min~max는 정수 균등 수량이며 획득 여부 추첨과 다르다. 온전한 표식만 정예 15%·레이드 25% 추가 추첨이고 외형 전용이다.

한 시체에서 집중 부위를 다시 고르거나 채널 이동·재접속으로 보상을 초기화하지 못한다. 일반 시체 권리는 300초, 단절 유예 120초를 초안으로 한다. 길어지는 해체 대기로 다음 활동을 막지 않는다.

레이드는 4인 HP를 기준으로 시작 인원 1/2/3/4/5/6/7/8명에 대해 HP 배율 0.35/0.55/0.8/1/1.18/1.36/1.54/1.72를 사용한다. 공격력은 유지하고 1~2명에는 다인 동시 조작이 필요한 패턴을 빼준다. 전투 시작 인원으로 고정하며 탈주해도 보스 HP를 낮추지 않는다.
