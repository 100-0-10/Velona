# 제작대와 생활 생산 레시피

JSON의 레시피와 설치 비용을 같은 자료에서 표로 출력한다. 건축 메뉴에서 설비를 설치하고 해당 제작대에서 작업한다. 작업 도구는 소비 재료가 아니라 보유·내구 조건이다. 물은 공용 저장 서비스에서 차감하며 연료는 통나무·숯으로 제공한다.

통나무 1개는 연료 1단위, 숯 1개는 2단위다. 미사용 열량은 연료칸에 남는다. 표에 숯이 입력 재료로 직접 기재된 제련 공정은 가열 비용이 포함되며 연료 열을 이중으로 부과하지 않는다.

| 석재 공방 | 목제 건축 부품 ×12 + 벽돌 ×20 + 목제 문 ×1 + 창문 부품 ×2 | 넓은 작업 공간·구획; 특정 필수 제작법 독점 없음 |

## 연속 생산과 사용 편의

초기에는 전처리·무두질·건조의 역할을 하나씩 배운다. 이후 연결된 개인 설비에 연속 예약한다. 작업 시작 재료는 소비, 대기 작업 재료는 잠금, 완료물은 수령 대기다. 시작 전 취소는 전액 반환하고 시작 후 취소는 반환하지 않는 규칙을 안내한다. 수령은 서버 작업 하나당 한 번만 가능하다.

제작 창은 완성품에서 원재료까지 역으로 펼쳐 보고 부족한 재료의 지역·생물·제작대를 연결한다. 같은 가죽이라도 고유 외피와 일반 가죽의 대체 가능 여부를 슬롯에 명시한다. 이름이 비슷하다는 이유로 자동 대체하지 않는다.

간이 작업대→범용 작업대, 조리대→화덕은 개선 후 하위 제작법을 유지한다. JSON recipe.station_id가 이전 시설을 가리켜도 업그레이드 시설의 기능 집합에 포함한다.

퇴비는 부패 식재료를 소비하고 밭으로 이어진다. 축산은 동물 입수 의뢰·사육·사료를 갖춘 후 도입한다. 낚시·축산이 초반 필수 장비를 독점하지 않는다.


## 선택 결합재와 품질 슬롯

장비 레시피의 inputs는 기본 조합이다. substitution_groups가 있는 경우 해당 항목만 정확히 하나의 선택지로 바꾸며 기본 재료와 대안을 모두 차감하지 않는다. 섬유끈·가죽끈은 기본 수량 또는 그 수량의 절반을 올림한 힘줄끈으로 교체할 수 있다. 힘줄끈 대안은 공격 스태미나 절감 5%인 light 특성을 추가한다. 같은 장비에 이미 light가 있으면 중복 증가하지 않는다. 이 규칙은 장비 레시피에만 적용한다.

예를 들어 돌창의 섬유끈 2개를 힘줄끈 1개로 바꾸면 공격력 16·거리 2.6m는 유지하고 기본 공격 소모 9가 8.55가 된다. 품질은 별도 계산한다. 서로 다른 장비의 수동 효과는 합산 후 상한을 적용하며 적중 발동 특성은 같은 종류 최고 하나만 적용한다.

material_slots는 각 재료를 주재료·보강재·결합재로 나누고 실제 사용 슬롯의 품질 가중치를 담는다. 고유 몬스터 장비는 첫 번째 고유 재료가 주재료다.
