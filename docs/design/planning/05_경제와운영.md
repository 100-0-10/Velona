# 경제와 생활 운영

## 공급과 소비

사냥·채집·농사·축산은 원재료를 공급한다. 보존·가공·제작은 시간과 전문 기술을 사용해 가치를 높인다. 음식·회복품·연료·건축·수리·장비 수명은 재료를 소비한다. 화폐는 NPC 의뢰로 공급하고 수리 비용·거래 수수료·시설 서비스로 회수한다. 재료 소멸과 화폐 회수는 따로 측정한다.

기본 화폐 1종과 고정가 거래소로 시작한다. 시장 수수료는 5% 시험값이다. 모든 물건의 무제한 고정가 판매는 넣지 않고 기본 생계 판매와 상한 있는 납품을 구분한다. NPC 가격·의뢰 보상·물가 목표는 실제 제작시간을 측정한 후 잡는다. 현재 데이터에 임의 가격을 채워 경제가 확정된 것처럼 취급하지 않는다.

## 부패·보관

원재료 고기·생선·식물성 식재료 기본 수명은 8시간, 기초 보존함은 6배 속도 완화, 초보 보호 보관은 제한된 수량에 72시간부터 시험한다. 보존식은 7일을 기준으로 한다. 모든 재료를 같은 부패율로 처리하지 않으며 완성품 수령 대기에는 부패를 적용하지 않는다.

기름·가죽·광물은 기본 부패 대상에서 제외한다. 동일 묶음의 신선도 병합은 낮은 값을 사용한다. 창고 이동·시장 등록·우편 반환으로 신선도와 내구를 초기화하지 않는다. 냉각 시설 연료 소진은 일반 보존으로 전환하며 즉시 전체 자원을 파괴하지 않는다.

## 거래와 소유권

시장 등록은 물품 잠금·소유 상태 전환을 함께 확정한다. 구매는 재화 차감·물품 이전·판매 수익·수수료를 하나의 거래로 처리한다. 동시 구매·연결 단절·요청 재시도에도 중복 이전이 없어야 한다. 등록 중인 물품은 장착·수리·생산 재료로 사용할 수 없다.

친구 방문 권한은 수확·시설 사용·창고·건축·철거로 나눈다. 공동 창고는 입출고·개인 작업·기부 이력을 남긴다. 탈퇴·해산 규칙과 개인 반환이 준비되기 전에는 공동 기부 건설만 제공한다. 제작 의뢰는 제공 재료·품질 조건·보수·취소 상태를 서버에서 잠그는 단계 이후다.

## 접속 끊김과 복귀

전투 단절 시 최대 15초 캐릭터가 남고 일반 AI의 공격 대상이 될 수 있다. 이후 안전 상태로 정리하며 다시 접속하면 서버 저장 위치 또는 가까운 안전지점에서 복구한다. 사망·지역이동과 경합하면 서버의 최종 상태를 사용한다. 120초 안 재접속이면 해체 권리를 복구한다. 브라우저 창 여러 개를 열면 캐릭터 행동 세션은 하나만 활성화한다.

시작된 생산은 서버 완료 시각을 사용하고 모든 개인 맵을 상시 실시간으로 돌리지 않는다. 작업 수령·시장·재화는 재시작 후에도 상태가 보존되어야 한다. 중요한 재산 변경은 즉시 영구 기록하고 이동 좌표는 주기적 저장을 사용한다.

## 운영에 필요한 기능

로그인·작업·아이템 이동·거래·보상·권한 변경의 상관관계 ID를 기록한다. 운영자는 조회·복구·지급·회수·제재 기능을 구분하며, 재산 조정은 이유·대상·이전/이후 값·담당자를 남긴다. 계정·채팅·신고 접근은 권한을 제한한다.

백업은 운영 DB와 외부 저장소로 나누고 복구 연습을 한다. 개발·테스트·운영 데이터를 분리한다. 기존 OCI 서버는 과거 대화의 개발 후보일 뿐 현재 접속·과금·ARM 호환·잔여 자원을 확인한 상태가 아니다. 이 작업에서는 접속·배포·결제 연결을 하지 않는다.

## 지표

첫 가방까지 시간, 한 장비의 수리까지 실제 사용시간, 집중 해체 선택 비율, 특성별 제작·장착 비율, 원재료/완성품 재고, 시간당 화폐 공급·회수, 시장 거래 성립률, 복귀 후 부패 손실, 지역별 체류·사망·단절을 본다. 레이드 평균 시간과 솔로 진행 가능성도 따로 측정한다.
