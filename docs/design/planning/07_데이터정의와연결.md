# 데이터 정의와 연결

## 정적 자료와 사용자 상태

data 폴더는 구현 전의 기획용 정적 JSON이다. 실행 코드·게임 서버·DB 스키마·클라이언트 소스가 아니다. 상위 공통 형식은 schema_version, content_version, status, records이다. rules.json의 records만 섹션 객체이며 다른 목록은 배열이다. 모든 파일의 status는 design_draft다.

영문 id를 안정적인 연결 키로 사용하고 한국어 name은 표시명으로 사용한다. 명칭을 바꿔도 id는 유지하며, 항목 폐기 시에는 대체·마이그레이션을 정의한다. 사용자 아이템에는 별도 instance_id·수량·품질·신선도·내구·원산지·소유 상태를 저장한다.

## 데이터 관계

regions → monsters → base_harvest / focus_options → items → recipes.inputs / outputs → equipment → traits.

stations의 설치 재료도 items를 참조한다. sources는 채집·해체·축산·재활용 같은 제작 외 공급처다. upgrades와 unlocks는 시설 개선과 기술 학습 조건을 기록한다. life_facilities는 밭·축사·주택처럼 일반 작업대와 다른 생산 공간이다. operations는 동일 아이템 상태에 적용하는 수리·염색·해체·개조 작업이다.

물과 열량은 서비스 자원이라 items에서 별도 물 아이템을 찾지 않는다. ammo와 실제 먹는 음식은 일반 아이템이다. 수식 문자열은 기획 설명이며 런타임에서 eval하는 스크립트가 아니다. 구현 단계에서 타입과 범위를 가진 규칙으로 옮긴다.

## 필드와 단위

세부 필드는 data_dictionary.json에 기록한다. 확률은 0~1, 퍼센트는 5처럼 0~100 단위, 저항은 점수, 시간은 초, 거리는 m, 수량은 양의 정수다. tier는 아이템 레벨과 다르다. 지역 T0은 tier 0이며 유통 아이템은 최소 tier 1로 표기한다.

고유 장비의 base_stats는 품질·특성 적용 전이다. 기본 피해 계산에서 해당 특성을 다시 중복 가산하지 않는다. armor의 attack_interval 0은 공격 불가라는 뜻이며 무한 공격속도가 아니다. null은 미정/해당 없음 중 필드 설명에 따라 읽으며 숫자 0과 구분한다.

## 이번에 정리한 이전 초안의 차이

- 연료 단위와 숯 직접 투입을 구분했다. 모루 공정의 가열 연료도 별도 열에 표시한다.
- 최초 모루·가마·연마대·가죽 설비는 자기 생산품 없이 설치한다.
- 돌칼·망치는 소모 입력이 아닌 도구 조건이다.
- 간이 작업대와 조리대는 개선 후 하위 레시피를 계속 지원한다.
- 원정 식량 배합은 조리대, 훈연은 훈연장에서 처리한다.
- 상급 털가죽·내열 갑각·철 화살이 아닌 초급 뼈 화살의 공급·제작을 명시했다.
- 몬스터 고유 가죽은 일반 가죽과 별도 항목이다. 일반 가죽을 대체 가능한 슬롯은 구현 때 명시하고 임의 자동 대체하지 않는다.
- 레이드 드롭의 기본 성능 부위는 확정 집중 해체, 희귀 표식은 외형 전용이다.
- 스태미나 절감·상태 이상·품질 배율·방패 장착 제한·레이드 인원 배율을 정의했다.

## 검증 범위

검증은 id 중복·누락 참조·양수 수량·확률 범위·제작 공급처·설비 설치 선행·해금 도달·모든 장비의 제작법·고유 재료에서 장비까지의 연결을 확인한다. 지역을 모두 탐험 가능하다고 두는 전체 콘텐츠 도달 검사와 초원·숲으로 제한한 첫 가방 도달 검사를 구분한다.

이 검사는 실제 채집 속도·경제 수익·재미·네트워크·프레임을 검증하지 않는다. 반복 가공에서 무료 자원이 만들어지는 모든 수치 조합, 시장 가격, 온라인 악용은 실제 규칙 구현과 시뮬레이션 단계에서 추가 검증한다.

## 다음에 구체화할 자료

맵 좌표·면적·채집 노드 수·스폰 밀도, 숙련도 곡선, NPC 가격·주문 수량, 모든 음식의 효과·회복량·재사용 시간, 포만감 감소, 축산 동물표, 상세 애니메이션·자산 예산, UI 배치, 계정 인증 서비스·운영 지역은 아직 별도 결정이 필요하다. 항목을 미정으로 남겼으며 이 패키지를 배포 가능한 완성 데이터로 사용하지 않는다.
