## 현재 규모

지역 10종, 몬스터 30종, 아이템 357종, 제작 인터페이스·설비 31종(손 제작·건축 메뉴 포함), 레시피 277개, 장비 93종, 특성 20종.

같은 몬스터의 고유 재료로 무기·방패 중 1종과 방어구 1종을 연결했다. 고유 성능 재료는 집중 해체로 확정 획득하며 희귀 표식은 외형 전용이다. 일반 가죽과 종별 고유 가죽은 서로 다른 항목이다.

## 개발 방향

PC 웹 쿼터뷰·TypeScript·Three.js·React·Vite, C# .NET 10 서버·SignalR 초기 실시간 연결, PostgreSQL을 제안한다. 채널 30명 목표, 개인 거점, 1~8인 별도 원정, 오프라인 예약 생산이다. 50명 확장은 부하 측정 이후다.

첫 시제품은 튜토리얼·초원·숲에서 사냥→해체→무두질→건조→가방·장비를 만드는 흐름을 연결한다. 모든 데이터를 처음부터 구현하지 않는다.

## 정적 데이터

data/*.json은 UTF-8이며 공통 schema_version·content_version·status·records 형식을 사용한다. 데이터 설명은 data/data_dictionary.json에 있다. 상태는 모두 design_draft이며 DB 사용자 상태·실행 코드와 구분한다.

검증 결과: 검사 1532개, 실패 0개. 공급·참조·선행 연결 검사이며 게임 플레이·서버 수용량·프레임 검증은 아니다.

## 미정 항목

맵 좌표·스폰 밀도·숙련도 곡선·아이템 가격·음식 상세 효과·축산 동물·자산 제작·운영 비용은 다음 단계에서 정한다. 소스·실행 파일·패키지 설치·서버 배포는 이번 작업에 포함하지 않았다.

검증 파일과 manifest.json의 파일 목록·SHA-256으로 전달본을 확인할 수 있다. 문서와 JSON 중 수량·능력치는 JSON을 기준으로 하며, 문서 표는 동일 자료에서 작성했다.
