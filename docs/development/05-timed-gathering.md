# 선택형 시간 채집과 숙련도

대상 조사 → 재료 목록 확인 → 원하는 재료 선택 → 진행 시간 경과 → 해당 재료 획득 순서다. 조사와 선택만으로 물건이 지급되지 않는다. 사체 해체도 같은 방식을 사용하며 각 부위를 따로 작업한다. 이전 집중 부위 묶음 즉시 지급은 폐기한다.

목록에는 이름·수량·등급·필요 숙련도·기본 시간·내 숙련도로 줄어든 시간이 표시된다. 값은 서버가 계산한다. 가격 변동이 타이머를 바꾸지는 않으며 각 재료의 채집 난도와 희소성에 기본 시간을 부여한다.

최대 레벨30, 레벨 L에 필요한 누적 경험치는10×L×(L−1)/2다. 완료한 작업에만 경험치를 주고 레벨당2%, 최대40% 시간을 줄인다. 예를 들어 기본8초 작업은 레벨10에서6.56초, 레벨21 이상에서4.8초다. 시작 시 시간을 확정하며 진행 도중 다른 효과로 다시 계산하지 않는다. 생산 시설의 개발용0.05배 설정은 직접 채집에 적용하지 않는다.

이동·실제 공격·피격·취소·접속 종료·대상 소멸 시 중단하고 재료·경험치를 지급하지 않는다. UI를 닫는 것만으로는 중단하지 않으며 하단 진행 표시에서 취소할 수 있다. 가공 설비의 예약 생산은 별개로 계속 진행할 수 있다.

자원은 선택한 재료 칸만 작업자에게 예약한다. 다른 사람은 같은 나무의 다른 재료를 작업할 수 있다. 취소하면 예약을 즉시 풀고, 완료하면 해당 칸에8초 재생 시간을 적용한다. 완료품 공간은 생산·채집 양쪽에서 예약해 가방 초과를 막는다.

사체는 유효 전투 참여자마다 개별 부위 권리를 가지며 부위별1회다. 서버는 개체 세대와 남은 사체 시간을 확인한다. 이전 방식으로 이미 해체한 사체 기록은 전부 사용한 것으로 해석해 업데이트 때문에 추가 보상을 만들지 않는다.

숙련 경험치와 재료별 재생 시각은 PostgreSQL 체크포인트에 저장한다. 진행 중인 직접 채집은 저장 복구하지 않고 중단한다. 기존 저장의 신규 필드는 기본값으로 처리한다. 원래 제작·생산 작업과 인벤토리는 보존한다.

데이터 기준은 docs/design/data/gathering.json이다. 기본 시간·수량·레벨·경험치는 밸런스 초안이며 실제 플레이로 조정한다.
