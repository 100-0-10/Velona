# Velona C# 개발 서버

.NET 10 기반의 첫 실시간 생활 게임 시제품이다. 게스트·인벤토리·작업·해체 권리를 PostgreSQL에 저장하고 재시작 시 복구한다. 정식 회원 계정과 운영 배포는 아직 없다. 저장은 별도 1초 체크포인트이며 강제 종료 직전 약 1초의 변경은 손실될 수 있다.

## 실행

저장소 루트에서 실행한다.

```powershell
dotnet run --project backend/Velona.Server
```

개발 프로필은 `http://localhost:5080`과 `Development` 환경을 사용한다. 프론트 개발 서버는 5173, 빌드 미리보기는 4173 포트를 허용한다. 다른 출처가 필요하면 `Cors:Origins`에 명시적으로 추가한다. 운영 환경에서 게스트 발급은 403을 반환하며 개발 프로필을 인터넷에 공개하지 않는다.

```powershell
dotnet test backend/Velona.slnx
dotnet publish backend/Velona.Server -c Release -o artifacts/backend
```

기획 JSON의 items/recipes/stations는 빌드·배포 결과의 `Content/Design`에 복사한다. 서버는 실행 파일 위치를 기준으로 로드하므로 실행 중인 작업 폴더에 의존하지 않는다. 배포 바이너리를 개발 시연하려면 `ASPNETCORE_ENVIRONMENT=Development`를 명시해야 한다.

## 현재 구현

- 30명 정원의 단일 `meadow-1` 채널과 개인 게스트 세션
- 20Hz 서버 이동·경계·간단한 원형 충돌·스태미나·안전지대 회복
- 별도 10Hz 개인화 스냅샷 전송, 느린 전송의 250ms 제한
- 공유 채집 지점, 돌턱멧수 추적·고정 위치 공격 예고·처치·개인 해체
- 기획 JSON에서 읽은 끈·수피 분말·가죽 전처리·무두질·건조·가방 제작
- 16종 기본 가방 칸, 작은 가방 보유 시 20종, 묶음별 99개 상한
- 재접속 중 작업 완료·1회 지급·결과 공간 예약
- 채팅 길이·속도 제한과 게스트 발급 제한

시작용 창·칼과 야영지 설비·공정용 물은 제공된다. 건설·정밀 내구·부패·식사·제작품 품질·전체 생활 분야는 후속 구현이다. 멧수 전투 수치는 첫 조작 검증용이며 원본 기획의 전체 전투 규칙을 아직 적용하지 않았다. 멧수 사체는 20초 후 다시 등장한다.

`Game:ProductionTimeScale`은 기본 설정에서 1.0, 개발 설정에서 0.05다. 따라서 기획상 240초인 무두질은 개발 시연에서 12초다. 완료품은 시제품에서 자동으로 1회 지급하며 기획의 수령 대기 방식은 이후 단계다. 토큰을 가진 같은 탭은 30일 게스트 기간 내 재접속·서버 재시작 후 위치·재료·작업을 이어갈 수 있다. 같은 세션의 새 연결은 이전 연결의 행동 권한을 대체한다.

## 행동 안전 규칙

좌표를 직접 보내서 이동시키지 않고 입력 방향만 보낸다. 서버가 유한 수치·방향 정규화·입력 순번을 검사한다. 350ms 동안 입력이 없으면 멈춘다. 채집 거리·재생 시간·공격 거리·재사용·해체 참여권·가방 공간·제작 재료를 서버가 검사한다.

재시도용 requestId는 최대 80자의 ASCII 영문·숫자·하이픈이다. 최근 128개 행동의 결과는 그대로 반환한다. 그 이전에 처리했던 ID도 세션별 압축 해시로 기억해 거절하며 다시 실행하지 않는다. 한 세션의 행동 한도는 65,536개다. 같은 requestId로 다른 행동을 실행할 수 없다. 해체는 별도로 사체 세대별 개인 권리를 기록한다.

운영용 인증·아이템별 거래 장부·수평 확장·30명 부하 검증은 아직 없다. 로컬 PostgreSQL 접속과 설정은 docs/development/04-local-postgresql.md에 있다. 건강 응답과 통신 계약은 `docs/development/01-initial-slice-contract.md`를 따른다.

PostgreSQL 접속은 .NET User Secrets의 ConnectionStrings:Velona 또는 환경 변수 ConnectionStrings__Velona를 사용한다. 초기 계정·DB 생성 스크립트는 scripts/setup-local-db.ps1이다. Persistence__Enabled=false는 격리 테스트에만 사용한다. /health는 저장 상태와 마지막 저장 시각을 표시한다. 저장소·로그에 비밀번호를 적지 않는다.

## 선택형 시간 채집

E 조사만으로 물건을 지급하지 않는다. 목록의 재료를 StartGather로 선택하고 실제 시간이 지나야 그 재료와 분야별 경험치를 얻는다. 기본 시간·최소 숙련·수량은 gathering.json에서 읽는다. 이동·공격·피격·취소·단절·대상 소멸 시 중단한다. 숙련은 PostgreSQL에 저장하며 직접 채집은 오프라인 진행하지 않는다. 기존 Harvest 호출도 단일 재료 시간 작업으로 연결한다. 자세한 규칙은 docs/development/05-timed-gathering.md를 따른다.
